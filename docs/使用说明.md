润博 E72 万科物业版本修复工具 · 使用说明
================================================

适用机型
--------
润博 E72（万科物业定制版，设备型号显示为 WKWY）
同批次的展讯 SC9850 / Android 8.1 定制对讲机亦可使用。
其他机型也能运行，本机没有对应组件时会自动跳过，不会报错。


使用方法
--------
1. 电脑装好 adb 驱动（Win10/11 插上一般自动识别；认不到再装厂商驱动）
2. 对讲机：设置 → 关于手机 → 连续点「版本号」7 次 → 开发者选项 → 打开「USB 调试」
3. 数据线连电脑，设备屏幕弹窗点「允许 USB 调试」
4. 双击运行 RadioFixTool.exe（改中文名不影响运行）
5. 顶部出现设备型号和四个绿色徽章后，点「开始一键修复」
6. 全部完成后工具会自动重启设备，约 1 分钟重新开机

工具已内置 adb 与全部依赖，不需要另外安装任何东西。


修复内容（均为可逆系统设置，不刷机、不改系统分区）
--------------------------------------------------
1) 修复拨号秒挂
   停用 com.runbo.sdk_service
   该服务在通话建立时读取白名单，号码不匹配就直接挂断，是「点拨号瞬间挂断」的元凶。

2) 壁纸不再被还原
   停用 com.tintele.DoDefaultSetting
   该组件每次开机把内置的定制壁纸强设回系统壁纸。

3) 恢复浏览器与短信
   重新启用 com.android.browser / com.android.messaging / com.android.quicksearchbox
   上面那个组件开机时会把它们禁用，所以之前手动打开也会被改回去。

4) 开启 VoLTE
   setprop persist.sys.volte.enable true

5) 免密码自由安装
   置位 sys.appinstall.state=1，并在缺失时安装「授权引导组件」（包名 runbo.android.poc）。
   背景：该 ROM 的安装总闸是一个非持久属性，重启即清零；本该由设置里的
   RestoreDataReceiver 开机同步回来，但它启动 runbo.android.poc 的登录页时找不到该类
   会抛异常中断，导致同步逻辑永远执行不到。补一个同包名占位组件后，
   开机流程能跑通，授权自动恢复，装软件不再需要输 WKWY1234。

6) 完成后自动重启
   让以上改动立即生效。


恢复原厂状态（返修或需要装原厂 POC 时）
--------------------------------------
adb shell pm enable com.runbo.sdk_service
adb shell pm enable com.tintele.DoDefaultSetting
adb uninstall runbo.android.poc
adb shell setprop sys.appinstall.state 0
adb reboot


注意事项
--------
* 杀毒软件提示「未知程序」属正常现象（自编译程序无数字签名），加信任即可。
* 以后若要安装原厂 POC/POT 对讲机应用，先执行 adb uninstall runbo.android.poc，
  否则会因签名冲突装不上。
* 设备列表为空：换一条数据线或换 USB 口；确认设备上已点「允许 USB 调试」。
* 工具通过 Edge / Chrome 的应用窗口显示界面，窗口关闭后如需完全退出，
  请在界面右上角点「退出」。
